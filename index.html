Gerador e leitor de Arquivo/Mensagem Criptografada

Escreva uma mensagem, defina uma senha e gere um arquivo .msg criptografado para levar no pendrive. Quem receber abre esta mesma página, escolhe o arquivo e clica em descriptografar. A árvore binária de Huffman é montada passo a passo na tela nos dois lados.

Montagem da árvore

Cada passo junta os dois nós de menor frequência num nó pai, até sobrar uma árvore só. Folhas em amarelo são os caracteres; nós internos em verde só carregam a soma das frequências.

Reconstrução da árvore

Depois de desfazer a criptografia, a árvore é remontada lendo os bytes recebidos em pós-ordem, com uma pilha: cada folha lida (com o caractere) é empilhada; cada nó interno lido desempilha os dois últimos nós montados e os torna seus filhos, empilhando o nó resultante.

Levando no pendrive

  1. Copie este arquivo PPMS.html para o pendrive.
  2. Na aba Criptografar, escreva a mensagem, defina uma senha e clique no botão. O navegador baixa um arquivo .msg — mova ele para o pendrive também.
  3. Combine a senha com a outra pessoa por outro canal (falando, ligando). A senha nunca vai dentro do arquivo.
  4. No outro computador, dê dois cliques no PPMS.html do pendrive: abre no navegador, sem instalar nada.
  5. Na aba Descriptografar, escolha o .msg, digite a senha e clique em Descriptografar.

Como funciona por dentro

  1. Conta quantas vezes cada byte aparece na mensagem.
  2. Monta a árvore de Huffman juntando sempre os dois nós menos frequentes — é essa montagem que aparece animada.
  3. Troca cada caractere pelo caminho dele na árvore (0 = esquerda, 1 = direita), gerando uma sequência de bits.
  4. Serializa a árvore em pós-ordem (filho esquerdo, filho direito e só então o nó pai) e junta num pacote: tamanho original, a árvore serializada e os bits codificados. Para reconstruir, o lado que recebe usa uma pilha: cada folha lida é empilhada e cada nó interno lido desempilha os dois últimos nós para virarem seus filhos.
  5. Cifra o pacote inteiro com um fluxo de bytes pseudoaleatório (splitmix64) derivado da senha por hash FNV-1a, aplicado com XOR. Sem a senha, o pacote não abre — nem a árvore é legível.

Observação honesta para a defesa do trabalho: a árvore de Huffman é compressão, não criptografia. Quem garante o sigilo é a cifra aplicada em cima do pacote. Ela é didática e bem mais fraca que AES-256, que seria a escolha num sistema real.

O formato do arquivo .msg é o mesmo do programa em C original (cabeçalho PPMS), então os dois lados são compatíveis entre si.
